FasdeqOS Handbook

An open-source rolling-release Linux distribution combining the pure power of Arch Linux with the intuitive, clean filesystem layout of Apple macOS.

ID: fasdeqos Type: Rolling Release Base: Arch Linux + Linux Kernel Filesystem: Btrfs (APFS model)

Chapter 1 — Introduction & Architecture

FasdeqOS is an open-source Linux operating system built directly on top of Arch Linux, designed for a smooth transition from macOS to the Linux ecosystem. It retains the upstream Linux Kernel, hardware drivers, and systemd foundation while providing a modern macOS-inspired filesystem hierarchy.

Filesystem Layout

FasdeqOS uses Btrfs subvolumes to emulate the clean structure of Apple APFS:

DirectorySubvolumeDescription
/ApplicationsApplicationsUser application packages, bundles, icons, binaries, and isolated dependencies.
/SystemSystemOperating system root volume containing core binaries and essential system services.
/LibraryLibraryGlobal settings, frameworks, shared system resources, and global configurations.
/UsersUsersUser accounts, personal files, documents, and individual configurations.
/VolumesVolumesMount points for external drives, secondary partitions, and network storage shares.
/bootBoot volumeUEFI bootloaders (GRUB, Limine, systemd-boot) and compressed Linux kernel images.
/rootRoot HomeAdministrative home directory for the superuser.
Legacy directories such as /usr and /etc are mounted within isolated stages behind the scenes, ensuring full software compatibility.

Package Management with pkg

FasdeqOS features a dedicated package manager called pkg with BSD-style syntax, operating as a high-level wrapper over pacman.

CommandPurpose
pkg install <package|file>Installs applications from repositories or local .tar.zst packages. Heavy applications are containerized automatically.
pkg uninstall <package>Removes installed applications and unregisters metadata.
pkg listLists installed applications in /Applications.
pkg search <text>Searches package repositories.
pkg info <package>Displays package metadata, dependencies, and size.
pkg updateRefreshes package databases and mirrors.
pkg upgrade [package ...]Upgrades the system and all applications.
pkg list-repoLists configured extra repositories.
pkg add-repo <url> [name]Adds a repository to the system.
pkg remove-repo <name>Removes a configured repository.
pkg kernel [list|use <name>]Lists or switches active Linux kernels (e.g. linux, linux-cachyos, linux-zen).
pkg sys <pacman args>Executes pacman directly on the /System volume for kernels, drivers, and low-level services.
pkg change-desktop <name>Switches desktop environment: plasma, gnome, cosmic, hyprland, niri, xfce, cinnamon, mate, lxqt.
pkg change-int <name>Switches userland between chimerautils (BSD) and BusyBox.
pkg cleanupClears local package cache and temporary directories.

Troubleshooting

  • No network inside a Virtual Machine: Ensure your hypervisor assigns a network adapter (VirtIO / NAT / Bridged). With QEMU, attach -net nic,model=virtio -net user.
  • USB Boot Failure: Disable Secure Boot in your UEFI/BIOS. Flash the ISO in DD mode using Balena Etcher or dd.
  • Steam & Wine compatibility: Traditional 32-bit binaries requiring legacy paths in /bin run through Distrobox containers (Chapters 4 & 5).

Chapter 2 — Installation

Manual installation allows building custom partitions, subvolumes, and minimal setups.

sgdisk --zap-all /dev/sdX
sgdisk -n1:0:+1M -t1:ef02 -n2:0:+512M -t2:ef00 -n3:0:0 -t3:8300 /dev/sdX
mkfs.fat -F32 -n EFI /dev/sdX2
mkfs.btrfs -L FasdeqOS /dev/sdX3
mount /dev/sdX3 /mnt
for v in root System Applications Library Users private; do
  btrfs subvolume create /mnt/$v
done
umount /mnt
mount -o compress=zstd:1,subvol=root /dev/sdX3 /mnt
mkdir -p /mnt/{System,Applications,Library,Users,private,Volumes,usr,lib,lib64,etc,var,tmp}
for v in System Applications Library Users private; do
  mount -o compress=zstd:1,subvol=$v /dev/sdX3 /mnt/$v
done
mkdir -p /mnt/private/stage/boot
mount /dev/sdX2 /mnt/private/stage/boot
pacstrap -K /mnt/private/stage filesystem glibc musl bash fish pacman util-linux kmod systemd linux linux-firmware mkinitcpio btrfs-progs grub efibootmgr sudo mesa

After bootstrapping and configuring the chroot, relocate the payload into the FasdeqOS hierarchy:

bsdtar -xpf fasdeqos-payload.tar.zst -C /mnt/private/stage
bsdtar -cpf - -C /mnt/private/stage/usr . | bsdtar -xpf - -C /mnt/System
rm -rf /mnt/private/stage/usr
mv /mnt/private/stage/etc /mnt/private/etc
mv /mnt/private/stage/var /mnt/private/var
mv /mnt/private/stage/root /mnt/private/var/root
rm -rf /mnt/private/stage

Chapter 3 — Migration from Arch

Migrate in-place from Arch Linux, Manjaro, Garuda, CachyOS, or Omarchy without losing data.

Requirements

  • Arch-based Linux distribution.
  • Root partition formatted with Btrfs.
  • UEFI system with Limine, GRUB, or systemd-boot.
  • Root permissions.
ModeOperation
Without backup (Recommended)GNU tools are replaced by chimerautils, apps move to /Applications, pacman is replaced by pkg, and old system files are removed upon verified boot.
With backupData is copied into /Users and the new layout while preserving the legacy distribution.
 
curl -fsSL https://raw.githubusercontent.com/Fasdeq13/fasdeqOS/main/fasdeqos-migrate -o fasdeqos-migrate
sudo -E bash fasdeqos-migrate

Script repository: GitHub.

Chapter 4 — Steam & Gaming

Run Steam and gaming titles in an isolated Distrobox container using CachyOS v3.

NVIDIA GPU:

distrobox create -i docker.io/cachyos/cachyos-v3:latest -n cachy-steam --nvidia --additional-flags-create "--device /dev/nvidiactl --device /dev/nvidia-uvm --device /dev/nvidia0 -v /Users:/Users"

AMD / Intel GPU:

distrobox create -i docker.io/cachyos/cachyos-v3:latest -n cachy-steam --additional-flags-create "--device /dev/dri -v /Users:/Users:rslave"

Install & Export Steam:

distrobox enter cachy-steam
sudo pacman -Syu steam
distrobox-export --app steam

Chapter 5 — Wine & Windows Applications

Install Wine into the cachy-steam container and export binaries to your host user PATH.

distrobox enter cachy-steam
sudo pacman -Syu wine winetricks wine-mono wine-gecko lib32-gnutls --noconfirm
distrobox-export --bin /usr/bin/wine --export-path ~/.local/bin
distrobox-export --bin /usr/bin/winecfg --export-path ~/.local/bin
distrobox-export --bin /usr/bin/winetricks --export-path ~/.local/bin

Desktop Shortcut:

nano /Users/$USER/.local/share/applications/myapp.desktop
[Desktop Entry]
Name=My Windows Application
Exec=distrobox-enter -n cachy-steam -- wine "/path/to/program.exe"
Type=Application
Terminal=false
Categories=Game;

FasdeqOS Handbook

Дистрибутив Linux со скользящей моделью обновлений (rolling release), объединяющий гибкость Arch Linux с удобной файловой структурой macOS.

ID: fasdeqos Тип: Rolling Release Основа: Arch Linux + Linux Kernel Файловая система: Btrfs (APFS-модель)

Глава 1 — Введение и структура

FasdeqOS — открытый дистрибутив Linux на базе Arch Linux, созданный для комфортного перехода с macOS на Linux. Он сохраняет официальное ядро Linux, аппаратные драйверы и systemd от Arch, реорганизуя структуру каталогов и управление пакетами.

Структура файлов

FasdeqOS использует субтома Btrfs для имитации файловой системы Apple APFS:

КаталогСубтомНазначение
/ApplicationsApplicationsПапка приложений пользователя, самодостаточные пакеты, иконки, бинарники и зависимости.
/SystemSystemСистемный том операционной системы, базовые файлы ОС и службы.
/LibraryLibraryБиблиотеки, общесистемные ресурсы, темы оформления и глобальные конфигурации.
/UsersUsersДомашние каталоги пользователей, личные документы и конфигурации.
/VolumesVolumesТочки монтирования внешних накопителей, дополнительных разделов и сетевых дисков.
/bootBoot volumeЗагрузчики (GRUB, Limine, systemd-boot) и сжатые образы ядер Linux.
/rootRoot HomeДомашний каталог суперпользователя root.
Стандартные каталоги /usr, /etc и /var скрыты и смонтированы внутри изолированных слоев, сохраняя бинарную совместимость.

Пакетный менеджер pkg

В системе используется пакетный менеджер pkg с BSD-синтаксисом, являющийся оберткой над pacman.

КомандаОписание
pkg install <пакет|файл>Установка приложений из репозиториев или файлов .tar.zst. Тяжелые приложения изолируются в контейнерах.
pkg uninstall <пакет>Удаление приложения и связанных данных.
pkg listСписок установленных приложений в /Applications.
pkg search <текст>Поиск пакетов в репозиториях.
pkg info <пакет>Информация о пакете, зависимостях и размере.
pkg updateОбновление баз данных пакетов.
pkg upgrade [пакет ...]Обновление системы и приложений.
pkg list-repoСписок подключенных дополнительных репозиториев.
pkg add-repo <url> [имя]Подключение стороннего репозитория.
pkg remove-repo <имя>Удаление добавленного репозитория.
pkg kernel [list|use <имя>]Просмотр и переключение активного ядра (linux, linux-cachyos, linux-zen).
pkg sys <аргументы pacman>Вызов pacman напрямую на томе /System для ядер, драйверов и служб.
pkg change-desktop <имя>Переключение рабочего стола: plasma, gnome, cosmic, hyprland, niri, xfce, cinnamon, mate, lxqt.
pkg change-int <имя>Переключение окружения утилит между chimerautils (BSD) и BusyBox.
pkg cleanupОчистка кэша пакетов и временных файлов.

Первая помощь

  • Нет сети в виртуальной машине: Убедитесь, что гипервизор выделил сетевой адаптер (VirtIO / NAT / Bridged). В QEMU используйте -net nic,model=virtio -net user.
  • Флешка не загружается: Отключите Secure Boot в UEFI. Записывайте ISO в режиме DD через Balena Etcher или dd.
  • Steam и Wine: Старые 32-битные библиотеки и программы запускаются через контейнеры Distrobox (Главы 4 и 5).

ID: fasdeqos Tipo: Rolling Release Base: Arch Linux + Linux Kernel File system: Btrfs (modello APFS)

Capitolo 1 — Introduzione e Struttura

FasdeqOS è un sistema operativo Linux open source basato su Arch Linux, progettato per facilitare il passaggio da macOS a Linux. Mantiene il Kernel Linux, i driver hardware e systemd, riorganizzando lo spazio utente e la struttura delle cartelle.

Struttura del File System

FasdeqOS impiega i sottovolumi Btrfs per riprodurre la gerarchia di Apple APFS:

CartellaSottovolumeDescrizione
/ApplicationsApplicationsApplicazioni utente, file binari, icone e dipendenze isolate.
/SystemSystemVolume di sistema con binari di base e demoni essenziali.
/LibraryLibraryLibrerie condivise, risorse di sistema e impostazioni globali.
/UsersUsersCartelle home degli utenti, documenti e configurazioni personali.
/VolumesVolumesPunti di montaggio per unità rimovibili USB e dischi secondari.

/rootRoot HomeCartella home dell'amministratore superuser.
Le cartelle UNIX legacy come /usr ed /etc sono protette in livelli isolati per garantire la piena compatibilità.

Risoluzione dei Problemi

  • Assenza di rete nelle VM: Assegna una scheda di rete VirtIO o NAT. In QEMU usa -net nic,model=virtio -net user.
  • L'USB non si avvia: Disattiva Secure Boot nel BIOS UEFI. Scrivi la ISO in modalità DD con Balena Etcher o dd.
  • Steam e Wine: I carichi legacy a 32 bit vengono eseguiti tramite container Distrobox (Capitoli 4 e 5).

Глава 1 — Вступ та файлова структура

FasdeqOS — відкрита операційна система Linux на базі Arch Linux, створена для плавного переходу з macOS на Linux. Вона зберігає оригінальне ядро Linux, драйвери та systemd від Arch, повністю оновлюючи структуру каталогів та керування софтом.

Структура файлів

FasdeqOS застосовує субтоми Btrfs для відтворення файлової структури Apple APFS:

КаталогСубтомПризначення
/ApplicationsApplicationsПапка застосунків користувача, ізольовані пакунки, іконки, бінарники та залежності.
/SystemSystemСистемний том операційної системи, базові файли ОС та системні служби.
/LibraryLibraryБібліотеки, загальносистемні ресурси, теми оформлення та глобальні налаштування.
/UsersUsersДомашні теки користувачів, особисті файли, документи та конфігурації.
/VolumesVolumesТочки монтування зовнішніх накопичувачів, флешок і мережевих сховищ.
/bootBoot volumeЗавантажувачі (GRUB, Limine, systemd-boot) та стислі образи ядер Linux.
/rootRoot HomeДомашній каталог суперкористувача root.
Стандартні теки /usr, /etc та /var приховані та змонтовані всередині ізольованих рівнів, зберігаючи повну сумісність.

Пакетний менеджер pkg

У системі працює пакетний менеджер pkg з BSD-подібним синтаксисом як надбудова над pacman.

Вирішення проблем

  • Немає мережі у віртуальній машині: Призначте машині мережевий адаптер VirtIO або NAT. Для QEMU використовуйте -net nic,model=virtio -net user.
  • Флешка не завантажується: Вимкніть Secure Boot в UEFI. Записуйте ISO в режимі DD через Balena Etcher або dd.
  • Steam та Wine: 32-бітні ігри та програми ізолюються за допомогою контейнерів Distrobox (Глави 4 та 5).

Глава 2 — Встановлення системи

Ручне встановлення системи для гнучкого налаштування дисків і розділів.

sgdisk --zap-all /dev/sdX
sgdisk -n1:0:+1M -t1:ef02 -n2:0:+512M -t2:ef00 -n3:0:0 -t3:8300 /dev/sdX
mkfs.fat -F32 -n EFI /dev/sdX2
mkfs.btrfs -L FasdeqOS /dev/sdX3
mount /dev/sdX3 /mnt
for v in root System Applications Library Users private; do
  btrfs subvolume create /mnt/$v
done
umount /mnt
mount -o compress=zstd:1,subvol=root /dev/sdX3 /mnt
mkdir -p /mnt/{System,Applications,Library,Users,private,Volumes,usr,lib,lib64,etc,var,tmp}
for v in System Applications Library Users private; do
  mount -o compress=zstd:1,subvol=$v /dev/sdX3 /mnt/$v
done
mkdir -p /mnt/private/stage/boot
mount /dev/sdX2 /mnt/private/stage/boot
pacstrap -K /mnt/private/stage filesystem glibc musl bash fish pacman util-linux kmod systemd linux linux-firmware mkinitcpio btrfs-progs grub efibootmgr sudo mesa

Після налаштування системи в chroot перенесіть файли у структуру FasdeqOS:

bsdtar -xpf fasdeqos-payload.tar.zst -C /mnt/private/stage
bsdtar -cpf - -C /mnt/private/stage/usr . | bsdtar -xpf - -C /mnt/System
rm -rf /mnt/private/stage/usr
mv /mnt/private/stage/etc /mnt/private/etc
mv /mnt/private/stage/var /mnt/private/var
mv /mnt/private/stage/root /mnt/private/var/root
rm -rf /mnt/private/stage

Глава 3 — Міграція з Arch

Перенесення з Arch Linux, Manjaro, Garuda, CachyOS або Omarchy без втрати особистих файлів.

Вимоги

  • Дистрибутив на базі Arch Linux.
  • Кореневий розділ Btrfs.
  • UEFI та завантажувач Limine, GRUB або systemd-boot.
  • Права root.
РежимДія
Без бекапу (Рекомендовано)Утиліти GNU замінюються на chimerautils, програми переїжджають в /Applications, pacman замінюється на pkg, стара система вилучається після завантаження.
З бекапомФайли дублюються в /Users і нову структуру зі збереженням старої конфігурації.
 
curl -fsSL https://raw.githubusercontent.com/Fasdeq13/fasdeqOS/main/fasdeqos-migrate -o fasdeqos-migrate
sudo -E bash fasdeqos-migrate

Скрипт на GitHub.

Глава 4 — Steam та ігри

Запуск ігор та Steam в ізольованому контейнері Distrobox на базі CachyOS v3.

Відеокарти NVIDIA:

distrobox create -i docker.io/cachyos/cachyos-v3:latest -n cachy-steam --nvidia --additional-flags-create "--device /dev/nvidiactl --device /dev/nvidia-uvm --device /dev/nvidia0 -v /Users:/Users"

Відеокарти AMD / Intel:

distrobox create -i docker.io/cachyos/cachyos-v3:latest -n cachy-steam --additional-flags-create "--device /dev/dri -v /Users:/Users:rslave"

Встановлення та експорт Steam:

distrobox enter cachy-steam
sudo pacman -Syu steam
distrobox-export --app steam

Глава 5 — Wine та програми Windows

Встановлення Wine у контейнері cachy-steam та експорт бінарників у PATH хоста.

distrobox enter cachy-steam
sudo pacman -Syu wine winetricks wine-mono wine-gecko lib32-gnutls --noconfirm
distrobox-export --bin /usr/bin/wine --export-path ~/.local/bin
distrobox-export --bin /usr/bin/winecfg --export-path ~/.local/bin
distrobox-export --bin /usr/bin/winetricks --export-path ~/.local/bin

Ярлик застосунку:

nano /Users/$USER/.local/share/applications/myapp.desktop
[Desktop Entry]
Name=Моя Windows Програма
Exec=distrobox-enter -n cachy-steam -- wine "/path/to/program.exe"
Type=Application
Terminal=false
Categories=Game;

FasdeqOS Handbook

基于 Arch Linux 的开源滚动发行版，将纯正的 Arch 性能与直观清晰的 macOS 目录结构融为一体。

ID: fasdeqos 类型: Rolling Release 基底: Arch Linux + Linux Kernel 文件系统: Btrfs (APFS 模式)

第 1 章 — 简介与系统架构

FasdeqOS 是基于 Arch Linux 构建的开源 Linux 发行版，旨在让用户能够从 macOS 平滑过渡到 Linux。系统保留官方 Linux Kernel、硬件驱动与 systemd 架构，同时将上层文件目录及软件管理重构为现代化的类 macOS 结构。

文件系统目录结构

FasdeqOS 利用 Btrfs 子卷 模拟 Apple APFS 的清晰层次结构：

目录子卷说明
/ApplicationsApplications用户应用程序目录，包含独立应用包、图标、二进制程序及隔离依赖。
/SystemSystem操作系统根卷，存放系统核心程序及核心服务。
/LibraryLibrary系统级共享资源、框架、桌面主题与全局配置文件。
/UsersUsers用户家目录、个人数据、文档及私人配置。
/VolumesVolumes外接可移动驱动器、扩展分区及网络共享挂载点。
/bootBoot volumeUEFI 引导程序（GRUB、Limine、systemd-boot）与压缩内核镜像。
/rootRoot Home超级管理员 root 的家目录。
/usr 和 /etc 等传统 Linux 目录挂载在底层隔离层中，确保软件生态的完全兼容。

软件包管理器 pkg

FasdeqOS 配备了采用 BSD 语法的专属 pkg 软件包管理器，底层调用 pacman 引擎。

命令功能说明
pkg install <包名|文件>从软件源或本地 .tar.zst 安装应用。重量级程序自动在隔离容器中运行。
pkg uninstall <包名>卸载指定应用并清理元数据。
pkg list列出 /Applications 中已安装的应用程序。
pkg search <关键词>在软件源中搜索匹配软件包。
pkg info <包名>显示软件包详情、依赖与大小。
pkg update刷新软件源镜像与同步数据库。
pkg upgrade [包名 ...]全面升级系统及所有已安装应用。
pkg list-repo查看已配置的扩展软件源列表。
pkg add-repo <url> [名称]添加第三方软件仓库。
pkg remove-repo <名称>移除指定的软件源。
pkg kernel [list|use <名称>]查看并即时切换运行内核（如 linux、linux-cachyos、linux-zen）。
pkg sys <pacman 参数>直接在底层 /System 卷上调用 pacman，建议仅用于内核、驱动和底层服务。
pkg change-desktop <名称>快速切换桌面环境：plasma、gnome、cosmic、hyprland、niri、xfce、cinnamon、mate、lxqt。
pkg change-int <名称>在 chimerautils（BSD 工具链）与 BusyBox 之间切换用户态环境。
pkg cleanup清理本地软件包缓存及临时文件。

疑难解答

  • 虚拟机无网络连接： 请确保虚拟机分配了网卡适配器（VirtIO / NAT / 桥接）。使用 QEMU 时添加 -net nic,model=virtio -net user。
  • U 盘无法引导： 在电脑 UEFI/BIOS 中关闭 Secure Boot。使用 Balena Etcher 或 dd 以原始 DD 模式写入 ISO。
  • Steam 与 Wine 兼容性： 传统 32 位程序依赖 /bin 路径，FasdeqOS 使用 Distrobox 容器进行隔离运行（参见第 4 与第 5 章）。

第 3 章 — 从 Arch 系系统迁移

支持从已安装的 Arch Linux、Manjaro、Garuda、CachyOS 或 Omarchy 原地无损迁移至 FasdeqOS。

前提要求

  • 基于 Arch Linux 的发行版。
  • 根分区为 Btrfs 文件系统。
  • UEFI 模式且使用 Limine、GRUB 或 systemd-boot 引导器。
  • Root 管理员权限。
模式说明
不备份（推荐）GNU 工具替换为 chimerautils，应用迁入 /Applications，pacman 替换为 pkg，首次成功启动后清理旧系统文件。
备份模式数据克隆到 /Users 与新目录结构中，同时完整保留旧系统以便回滚。
 
curl -fsSL https://raw.githubusercontent.com/Fasdeq13/fasdeqOS/main/fasdeqos-migrate -o fasdeqos-migrate
sudo -E bash fasdeqos-migrate

脚本源码：GitHub。

AMD / Intel 显卡：

第 5 章 — Wine 与 Windows 应用

在 cachy-steam 容器内配置 Wine 并将二进制程序导出到宿主机用户 PATH。

distrobox enter cachy-steam
sudo pacman -Syu wine winetricks wine-mono wine-gecko lib32-gnutls --noconfirm
distrobox-export --bin /usr/bin/wine --export-path ~/.local/bin
distrobox-export --bin /usr/bin/winecfg --export-path ~/.local/bin
distrobox-export --bin /usr/bin/winetricks --export-path ~/.local/bin

创建桌面快捷方式：

nano /Users/$USER/.local/share/applications/myapp.desktop
[Desktop Entry]
